# Scan bersama

Direction approved by the owner: light document archive, warm white, dark text, deep green accent; thumbnail gallery, search, and document preview. Temporary product name as plain text, no logo.

Reading this as: a shared scan archive for office staff, in a paper archive visual language, dial ENERGY 1 / RHYTHM 2 / MOTION 1.

- Warm white (#f5f3ed) gives white scanned paper a visible edge.
- Ink (#202b27) is used for readable text; muted text (#52605a) remains legible against paper.
- Deep green (#175640) marks the main action and selected state, like an archive stamp.
- Segoe UI uses the Windows office environment's familiar letterforms without downloading fonts.
- A compact masthead, search shelf, and paper thumbnail grid put document identification ahead of administration.
- Document tiles repeat because users compare pages; they are real document previews, not marketing feature cards.
- Gallery uses one, two, then three/four columns as space allows; preview fills a dialog on narrow screens.
- Paper frames, file type text, and timestamp labels repeat the archive motif.
- Rounded corners are limited: paper stays square; buttons/fields use 6px; dialog uses 12px.
- No decorative icons, illustrations, avatars, statistics, animations, external fonts, or background patterns.
- Hover/focus feedback only. Automatic refresh updates content without moving focus or closing the preview.
- All UI copy is Indonesian, direct, and specific to finding and downloading scans.

## Penghapusan dokumen

Tindakan hapus berada dalam preview agar admin bisa memeriksa dokumen sebelum menghapus. Merah memakai warna error yang sudah ada untuk membedakan tindakan hapus dari download. Konfirmasi muncul dalam dialog yang sama, menampilkan nama file, dan memfokuskan Batal; tombol membungkus pada layar sempit. Pengguna biasa tidak menerima kontrol hapus.
